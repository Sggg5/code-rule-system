# ERP Code Rule System

Single-file HTML product master data generator for ERP coding rules.

## Preview

Open `index.html` directly in a browser.

## Features

- Generate product codes from ERP rule fields.
- Auto-generate product name, ERP name, English name, specification, unit, material, and category.
- Show code breakdown and duplicate hints with mock/local data.
- Save recent generated records in localStorage.
- Export product master data as CSV.
